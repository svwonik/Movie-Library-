# Movie-Library

Простая библиотека фильмов с графическим интерфейсом на Python (Tkinter) и хранением данных в JSON.

## Функциональность

Приложение позволяет:
* добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга (0–10);
* просматривать список всех фильмов;
* фильтровать фильмы по жанру и году выпуска;
* сбрасывать фильтры;
* автоматически сохранять данные в файл `movies.json`.
